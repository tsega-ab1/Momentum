Momentum Color Workspace — gallery assets

Extract this ZIP at the root of your Momentum project. It will create:
public/assets/color-gallery/

The folder contains 14 original images organized into abstract-art, paint-textures,
color-palettes, and material-studies, plus gallery-manifest.json.
Images are unchanged; only filenames and folder organization were changed.

This package installs the assets only. The gallery UI still needs to be connected
inside the existing Color Workspace component.
